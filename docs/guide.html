Trạm trung chuyển ngôn ngữ · Language transit desk

Zen Assistant — Hướng Dẫn Sử Dụng

Bot dịch tự động cho server, giúp thành viên từ nhiều quốc gia trò chuyện bằng ngôn ngữ của riêng mình. Auto-translate bot for the server, so members from many countries can chat in their own language.

Cách hoạt động How it works
01

Nhắn tin bình thường, bằng bất kỳ ngôn ngữ nào. Type your message normally, in any language.

02

Bot tự nhận diện ngôn ngữ gốc — không cần gõ lệnh. The bot detects the source language automatically — no command needed.

03

Bot trả lời (reply) ngay bên dưới với bản dịch sang các ngôn ngữ khác. The bot replies underneath with translations into the other active languages.

Dành cho tất cả thành viên For everyone
/mute-language toggle code
Bật/tắt: từ giờ tin nhắn của riêng bạn sẽ không dịch sang ngôn ngữ đó nữa. Ví dụ: code:de Toggle a language off for your own messages only. Example: code:de
/mute-language list
Xem các ngôn ngữ bạn đang mute cho tin nhắn của mình. See which languages you've muted for your own messages.
/translate-status
Xem ngôn ngữ đang hoạt động, phạm vi kênh, model AI và số bản dịch đang cache. View active languages, channel scope, AI model, and cached translation count.
Dành cho quản trị viên For admins Manage Server
/translate-languages set codes
Đặt lại toàn bộ danh sách ngôn ngữ của server. Ví dụ: codes:vi,en,ja,ko,zh-CN,de Replace the server's entire language list. Example above.
/translate-languages list
Xem danh sách ngôn ngữ hiện tại. View the current language list.
/translate-channel ignore
Bật/tắt loại trừ kênh hiện tại khỏi tự động dịch. Toggle excluding the current channel from auto-translate.
/translate-channel only
Bật/tắt: thêm kênh hiện tại vào danh sách "chỉ dịch ở đây". Toggle adding the current channel to the "only translate here" list.
/translate-channel reset
Xóa mọi giới hạn kênh — dịch trở lại ở mọi nơi. Clear all channel restrictions — translate everywhere again.
/translate-channel status
Xem kênh hiện tại có đang được dịch hay không. Check whether the current channel is being translated.
